# williamjstribling.com

Static site, no build step. Served by GitHub Pages from `main`.

```
index.html                  Work (home)
music-videos/               Music video portfolio
screenwriting-coach/        Coaching, teaching, script consulting
about/                      Full bio
private-clients/            Redirect to /screenwriting-coach/ (old Squarespace URL)
404.html                    Not-found page
assets/css/site.css         All styles
assets/js/site.js           Click-to-play video thumbnails
assets/img/                 Images rescued from Squarespace, Sept 2026
CNAME                       Custom domain
robots.txt, sitemap.xml     Search
.nojekyll                   Skip Jekyll processing
```

To edit a page, edit its `index.html`. To change type, color or spacing,
edit `assets/css/site.css` — every page shares it.

Earlier drafts of a different version of this site (classes, directing,
resources, protagonist worksheet) live in the private `stribling-site-drafts`
repo.
